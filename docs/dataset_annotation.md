# 中畦YOLO-segアノテーションツール

`dataset_annotator.py`は、`dataset_prepare.py build`で構築した完成データセットの
Left画像へ、中畦クラスのUltralytics YOLO segmentationラベルを作成するローカルWebツールである。
元画像、Right、Depth、`metadata/manifest.csv`は変更しない。

## 起動

`zed_dataset_tools`ディレクトリから実行する。

```bash
python3 scripts/dataset_annotator.py \
  ../dataset_field_bund/data0001_20260611-12_ehime
```

既定URLは`http://127.0.0.1:8767`である。ポートを変更する場合：

```bash
python3 scripts/dataset_annotator.py DATASET_DIR --port 9001
```

終了は起動したターミナルで`Ctrl-C`を押す。既定ではlocalhostだけに公開する。

## 作業範囲

画像一覧と対応関係は`metadata/manifest.csv`から取得する。保存済み`output.root`ではなく、
起動引数の`DATASET_DIR`を基準にすべてのパスを解決する。

単独増分と累積セットを区別して選択できる。

- 単独`add010`: 各siteの新規10枚だけ
- 単独`add030`: 各siteの新規30枚だけ
- 累積`n010`: `add010`
- 累積`n040`: `add010 + add030`
- 累積`n100`: `add010 + add030 + add060`
- 累積`n200`: 全増分

site、処理状態、image IDでも絞り込める。状態は実際のTXTファイルから判定し、
manifest内の構築時点の`label_status`には依存しない。

## 境界入力

保存対象は常にLeft画像である。アノテーションCanvasの背景は`Left`、`Depth`、`Lateral`を
切り替えられ、切り替えても境界点、終端、生成マスクは同じ正規化座標のまま維持する。
RightとDepthは右側の参照欄にも表示できる。

### Lateral Depth

`Lateral`は、各画像行の有効Depth中央値をその行の基準距離とし、
`baseline(y) - depth(x, y)`をTurboカラーマップで表示する。基準距離は縦方向に移動中央値で
平滑化し、行ごとのDepthノイズによる横縞を抑える。これにより、手前から奥への大きな
距離勾配を色から外し、同じ距離帯にある左右方向の差を強調する。

暖色は同じ行の基準より手前、寒色は基準より奥、緑付近は行の基準距離を表す。
無効Depthだけを黒で表示する。表示幅は±100mm、±250mm、±500mm、Autoから選択でき、
固定幅は画像間の比較、Autoはフレーム内の小さな左右差の確認に向く。既定値は±250mmである。

Lateral Depthは実高さや安全性を示すものではない。また、対象が行の有効画素の過半数を占める場合は
その対象自体が中央値になり得るため、Raw Depthと併用して判断する。

### Line

左境界2点、右境界2点を順番に指定する。各2点を通る直線で画像矩形を切り、
両直線に挟まれた領域を生成する。

### Curve

左境界を上から下へ複数点入力して確定し、同様に右境界を入力する。
点列をCatmull–Romスプラインで補間し、端点の接線方向へ画像境界まで延長する。

### 画像内の終端

遠端は画像ごとに次から選択する。

- `画像外まで続く`: 左右境界間の領域を画像境界まで使用する
- `画像内で終了（2点）`: 終端上の任意の2点G1/G2を指定する

G1/G2は水平に制限しない。2点を通る無限直線で左右境界間の領域を切り、
左右境界の手前側中点と同じ半平面だけを残す。このため、右上がり・右下がりの終端と
G1/G2のどちらの入力順にも対応する。終端線は紫の破線で表示する。

点はドラッグして修正できる。`Undo`は最後の点を戻し、`Clear`はCanvas入力だけを消す。
保存済みラベルを削除する操作とは異なる。

## 保存

通常ラベルは画像と同じsite/addディレクトリへ保存する。

```text
images/site03_add010/20260611_141028_007140.jpg
labels/site03_add010/20260611_141028_007140.txt
```

TXTは1画像1領域、クラスID 0のYOLO segmentation形式である。

```text
0 x1 y1 x2 y2 ... xN yN
```

座標は0～1の正規化値で、小数点以下6桁で保存する。ポリゴンは3～512点、
3つ以上の異なる点と有効面積を必要とする。Curveの外周はブラウザからの送信前に
最大120点へ間引く。

「対象なし」は空のTXTを保存する。TXTがなければ未処理、空なら対象なし、
有効な1行があればラベルありとして扱う。

ラベルと同時に、再編集用の入力状態を保存する。

```text
metadata/annotation_state/<image_id>.json
```

ここにはLine/Curve、左右制御点、終端モードとG1/G2を記録する。Ultralyticsが読むのは
TXTだけであり、JSONは学習データへ影響しない。既存のsidecarなしYOLOラベルも表示できるが、
元の制御点は復元できないため、編集時はClearして描き直す。

ラベルとsidecarは同じディレクトリ内の一時ファイルへ書き、`os.replace()`で置換する。

## 操作

- `←` / `→`: 前後画像
- `L` / `D` / `T`: Canvas背景をLeft / Depth / Lateralへ切り替え
- `Ctrl+S`: 保存して次へ
- `Ctrl+Z`: Undo
- `対象なし・次へ`: 空TXTを保存して次へ
- `ラベル削除`: TXTと対応sidecarを削除して未処理へ戻す

未処理フィルターで保存すると、完了した画像は一覧から外れ、同じ位置に次の未処理画像が入る。
画像切替時は次のLeft画像を先読みする。

## 学習準備表示

画面上部に`n010`、`n040`、`n100`、`n200`ごとの完了数を表示する。対象YAMLに含まれる
全画像が通常ラベルまたは空ラベルになったときだけチェックが付く。途中状態のYAMLで学習すると、
未ラベルの中畦画像が背景として扱われる可能性があるため、チェック後に学習する。

## 現在の範囲

- クラス0の1画像1領域に対応する
- 終端は直線2点に対応する
- 画像内に複数の独立した中畦領域があるケースは未対応
- 終端曲線は未対応。必要になった場合は終端点列と半領域を追加する
