# 完成データセットビューア

`dataset_viewer.py`は、`dataset_prepare.py build`で構築したデータセットを変更せずに閲覧するローカルWebビューアである。Left、Right、16-bit深度を同じ`image_id`で切り替えられる。

## 起動

リポジトリのルートで次を実行する。

```bash
python3 scripts/dataset_viewer.py \
  ../dataset_field_ridge/data0001_20260611-12_ehime
```

表示されたURLをブラウザで開く。既定値は`http://127.0.0.1:8766`である。終了するときは起動したターミナルで`Ctrl-C`を押す。

ポートまたは1ページの枚数を変える場合：

```bash
python3 scripts/dataset_viewer.py DATASET_DIR \
  --port 9000 \
  --page-size 24
```

既定ではローカルホストだけに公開する。別端末から閲覧する目的で`--host`を変更する場合は、ネットワークからデータセット画像へアクセスできる状態になる点に注意する。

## 対象データセット

指定ディレクトリには`metadata/manifest.csv`が必要である。ビューアはmanifestの以下の列を使って画像を対応付ける。

- `image_id`
- `site_id`、`session_id`
- `increment_group`
- `left_path`、`right_path`、`depth_path`
- `sample_order`、`actual_frame_index`

画像ディレクトリをファイル名だけで走査しないため、Left、Right、Depthはmanifestに記録された同一サンプルとして表示される。データセット外を指す画像パスは配信しない。

## フィルター

追加グループは複数選択できる。たとえば`add010`と`add030`を有効にすると、両グループの和集合を表示する。

累積プリセットは、manifest内の増分を小さい順に累積して生成する。10、30、60、100の構成では次のようになる。

- `n010`: add010
- `n040`: add010 + add030
- `n100`: add010 + add030 + add060
- `n200`: add010 + add030 + add060 + add100

siteも複数選択でき、追加グループとのAND条件になる。image ID検索、選択順・site/add順・image ID順の並べ替えにも対応する。

## 表示操作

画面上部またはキーボードで表示対象を切り替える。

- `L`: Left
- `R`: Right
- `D`: Depth
- `←` / `→`: 前後または前後ページ
- `G`: グリッドへ戻る

グリッド画像を選択するとフォーカス表示になる。フォーカス表示では次の画像を先読みする。3,600枚などの全件を選択しても、一度に全画像をブラウザへ読み込まず、ページングと遅延読み込みを行う。

## 深度表示

動的深度表示は、単位mm・無効値0の16-bitグレースケールPNGを対象とする。既存の8-bit `depth_preview` は使わず、`depth_path`の値を表示時に疑似カラー化する。

設定項目：

- カラーマップ：Turbo、Viridis、Magma、Grayscale
- 最小距離、最大距離
- 0.5–5m、0.5–10m、0.5–20m、0.5–40mプリセット
- Gamma 0.2～3.0
- 近距離を暖色にする色方向の反転
- 画像ごとの自動範囲

「画像ごと自動」は各画像の有効深度における2～98パーセンタイルを使用する。1枚の奥行き構造を詳しく見る用途には向くが、画像ごとに色と距離の対応が変わるため、複数画像の距離比較には固定範囲を使用する。無効深度は黒で表示する。

設定はブラウザのローカルストレージへ保存する。データセットディレクトリにはサムネイル、キャッシュ、設定ファイルを作成しない。

## 制限

- 動的疑似カラーは16-bit PNG深度に対応する。NPY深度の単位はmanifestだけでは判定できないため対象外とする。
- このツールは閲覧専用であり、レビュー判定やラベルを保存しない。
